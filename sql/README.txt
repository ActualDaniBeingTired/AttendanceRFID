Using the Schema.sql  
1. Install PostgreSQL.
2. Make a new Database named AttendanceRFID or whatever you want it to be called. 
3. Use the QueryTool and change the Workspace to AttendanceRFID(YOUR_DATABASE) 
4. Copypaste and run "Schema.sql" on the query, It's to create the schema for our database. Students table is filled with the list of students. Cards table is filled with the assigned student's card, mind you- that one student may own 2 or more cards. Attendance table to show what student attend or they're absent THIS IS THE MAIN ONE, THE IMPORTANT ONE. The last is Unknown table that is filled with unknown. 

5. Copypaste and run "FakeDataForAttendanceRFID.sql" on the query. it's to make a fake data so we can use the Query

6. Use the other listed SQL to test the database or make your own ^^
